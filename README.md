# Taxfin Consulting

Single-page marketing site for Taxfin Consulting: bookkeeping, GST and TDS filing, financial statements and audit support.

Plain HTML, CSS and vanilla JavaScript. No build step. Open `index.html` in a browser or deploy the folder to any static host.

## Brand assets

All logo files live in `assets/`:

- `logo-mark.svg` — the TF monogram on a navy tile (favicon, app icons)
- `logo-mark-transparent.svg` — the monogram with no tile, for light backgrounds
- `logo-mark-512.png` — 512×512 PNG of the tile mark
- `logo-lockup.png` — mark plus wordmark for light backgrounds
- `logo-lockup-white.png` — mark plus wordmark for dark backgrounds
- `og.png` — 1200×630 social preview image

Colours: navy `#0B1D33`, gold `#C9A227`, light gold `#E3BE4C`.
